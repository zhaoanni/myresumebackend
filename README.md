This repository contains the backend code for my self-created resume web application.
The frontend part is hosted separately in the myresume repository.

Tech Stack
Node.js

Express

Axios

MySQL

dotenv for environment variables

Features
Handles contact form submissions from the frontend

Stores submitted data (name, email, message) into a MySQL database

Communicates with the frontend via JSON-based API (POST /api/contact)

CORS and JSON body-parsing configured for smooth frontend-backend communication.
